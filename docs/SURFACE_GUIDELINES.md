# Theme Lab Surface Guidelines

## Core rules

1. A page section has one outer surface owner.
2. Only the first segment owns the top radius.
3. Only the final segment owns the bottom radius.
4. Nested panels and joined middle segments use square corners.
5. Joined segments meet without vertical gaps or duplicated borders.
6. Padding creates internal separation; nested rounded cards do not.

## Post composer

The post header, form fields, SCEditor, attachment tray, options, and action row are treated as one continuous composer surface. The post header owns the top radius. Nested editor and attachment elements remain square.
