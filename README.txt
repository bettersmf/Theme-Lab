Theme Lab 1.0.1
=================

Theme Lab is an SMF 2.1.x administration modification for visually designing, previewing, saving, importing, editing, and publishing Curve2-based themes.

Quick Start
-----------
1. Install through Administration Center > Package Manager.
2. Open Administration Center > Configuration > Theme Lab.
3. Run Environment Check.
4. Create a Workspace or import a Theme Lab workspace/theme.
5. Configure the design through the Studios.
6. Review the completed design.
7. Publish the installable SMF theme ZIP.

Uninstall
---------
Theme Lab files/hooks are always removed. Leave SMF's database-removal option unchecked to preserve saved Workspaces for reinstall. Enable database removal only when you intentionally want to delete all Theme Lab Workspace data. Published themes are independent and are not removed.

Requirements
------------
SMF 2.1.x, PHP 7.0+, writable Themes directory, and ZIP support for publishing. GD is optional.
