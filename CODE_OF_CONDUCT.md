# Code of Conduct

Theme Lab is built through practical collaboration. Participants are expected to make the project safer, clearer, and more welcoming for others.

## Expected behavior

- Be respectful, patient, and specific.
- Critique code and decisions rather than people.
- Assume good intent while still asking for evidence and testing.
- Credit the work of others accurately.
- Admit mistakes and correct them openly.
- Keep technical disagreement focused on project goals and facts.
- Respect privacy and responsible security disclosure.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, deliberate disruption, doxxing, sexualized conduct, repeated bad-faith argument, plagiarism, or publishing private security details without authorization are not acceptable.

## Scope

This code applies in project repositories, issue trackers, reviews, documentation, community discussions, and private project communications when the conduct directly affects participation in Theme Lab.

## Enforcement

Concerns should be reported privately to the project maintainer. Reports will be reviewed in context. Responses may include clarification, a warning, content removal, temporary limits, or permanent exclusion from project spaces.

Good-faith reports will be handled as confidentially as practical. Retaliation against a reporter or witness is not acceptable.

## Attribution

This policy is informed by common open-source community standards while being written specifically for Theme Lab’s current size and maintainership.
