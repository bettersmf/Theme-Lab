# Theme Lab Roadmap

Theme Lab 1.0.1 is in public-release stabilization. New feature work should remain deferred until the 1.0.1 package completes clean-install/runtime acceptance.

## 1.0.1 — Public release acceptance

- Complete regression testing and release acceptance.
- Correct release-blocking defects only.
- Keep documentation synchronized with shipped behavior.
- Complete fresh-install, publish, uninstall-preserve, uninstall-remove-data, and reinstall acceptance on a clean SMF 2.1.x forum.

## 1.0.1 — Conversion & Customization

### Theme Converter

- Import standard SMF and third-party themes for conversion into a new Theme Lab Workspace.
- Analyze recognized colors, typography, layout, header/footer, and component styling.
- Never modify the source theme during conversion.
- Produce a conversion report showing values imported, approximated, or unsupported.

### Advanced layout

- Column controls and additional layout regions.
- Custom button placement controls.

### Footer expansion

- Footer background image support.
- Optional link from generated themes to the Theme Lab project page.

### Icon Studio

- Font Awesome package/library upload support.
- SVG package/library upload support.
- Icon library management and assignment to supported navigation, button, and interface targets.
- Live preview of icon assignments where practical.

Future contents remain subject to compatibility, security, and maintainability review.
